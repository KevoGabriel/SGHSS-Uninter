# SGHSS – Sistema de Agendamentos (Protótipo UI) - Um projeto pela Uninter

Este projeto é um protótipo visual de um sistema de agendamentos hospitalares, desenvolvido com foco em design de interface, navegabilidade, consistência visual e uso de tecnologias modernas do mercado front-end.
Não se trata de um produto final, mas sim de uma representação navegável das principais telas e fluxos do sistema.

O design não possui validação de login, então qualquer coisa pode ser passado para o campo para entrar no sistema (visual).

🎯 Objetivo do Projeto

Criar uma interface clara, moderna e responsiva para demonstrar como poderia funcionar o fluxo de um sistema de agendamentos utilizado por profissionais da área da saúde.
O foco está em UI/UX, organização de componentes e estruturação de telas que representem um fluxo realista de uso.

🧩 Tecnologias Utilizadas

React – Biblioteca principal para construção da interface.

Vite – Ferramenta de build rápida, ideal para desenvolvimento moderno.

TypeScript – Tipagem estática para maior segurança e clareza no código.

Tailwind CSS – Estilização utilitária, garantindo consistência e rapidez.

🔄 Fluxo Principal

O usuário inicia pela tela de Login e, após autenticação, acessa o Dashboard, que centraliza as informações gerais.
A interface permite navegar para telas como:

CreateAppointment – criação de consultas

WaitingList – lista de espera

History – histórico de atendimentos

Statistics – visão geral em números

Profile e Settings – gerenciamento pessoal e preferências

A navegação é guiada pelo componente BottomNav, garantindo simplicidade e continuidade na experiência.

📌 Status do Projeto

🟦 Protótipo funcional focado apenas em design e fluxo visual.
Não contém back-end, autenticação real ou lógica completa de operações.

🚀 Como executar
npm install
npm run dev


A aplicação ficará disponível em:

http://localhost:5173/

📝 Considerações Finais

Este projeto serviu como exercício de design, estruturação de telas e exploração das tecnologias modernas do front-end.
Reforçou a importância de planejar antes de implementar, documentar decisões e pensar sempre na experiência do usuário.
